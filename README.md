# Rom Lee Music — romlee.net

Neue Website für Rom Lee Music (YouTube-first).

## Starten

```bash
npm install
npm run dev
```

Im Browser: http://localhost:8080

## Build

```bash
npm run build
```

## Inhalt

- Songs, Videos, Songtexte, Fotos, Blog, Spotify-Hinweis
- Impressum und Datenschutzerklärung (DE)
- Live-Zahlen von YouTube (Abos, Aufrufe)
- Lokales Video: *Ich habe dich gewollt* (`public/videos/immer-schon.mp4`)

## Hinweis

YouTube-Player erst nach Einwilligung. Covers liegen lokal unter `public/images/covers/`.
